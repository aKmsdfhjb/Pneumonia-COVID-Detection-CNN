# Chest X-ray CNN Research — Video Production Brief

**Target:** 40 seconds, 16:9, 1080p  
**Visual direction:** Editorial Swiss / architecture-inspired portfolio design: warm ivory canvas, high-contrast black serif titles, fine hairline rules, small vermilion monospaced labels, restrained grid layouts, compact project metadata. Use real repository screenshots and screen recordings; no generic robot imagery, fake dashboards, fabricated metrics or invented testimonials.

## Creative direction

A research explainer, not a medical product advertisement. Show notebook/code and the static project page. Clearly label it “RESEARCH PROTOTYPE — NO DEPLOYED INFERENCE”. Do not display diagnostic predictions or imply clinical validity.

## Shot list

0–6s: title and research-prototype label. 6–16s: dataset governance and patient-level split. 16–27s: preprocessing, CNN training and held-out evaluation flow. 27–35s: list the missing validated weights and API. 35–40s: educational-use disclaimer and repository.

## Voiceover draft

An educational computer-vision research project exploring chest X-ray classification. Present the pipeline and validation requirements; do not depict diagnosis or clinical use.

## Production checklist

- Capture the current app from the repository; do not invent screens.
- Blur or exclude private data, credentials, tokens and personal information.
- Use only assets the repository owner has permission to publish.
- Verify any prediction, API response or feature shown in the edit.
- End with the repository name and a short GitHub URL.
- Export MP4 (H.264), 1920×1080, 24 or 30 fps, with readable captions.

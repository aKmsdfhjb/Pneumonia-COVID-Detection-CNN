# Chest X-ray CNN Research — Project Wiki

Research prototype for exploring three-way chest X-ray classification: Normal, Viral Pneumonia and COVID-19. The static project page is documentation only; the repository does not currently contain validated deployable weights or a working inference API.

## Quick start

Use the notebooks to inspect the research workflow. Before training, document the dataset source and license, patient-level split, preprocessing, and reproducible environment.
